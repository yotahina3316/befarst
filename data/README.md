# data/ (非公開データ)

このディレクトリは GitHub Pages では公開されない(`frontend/` のみが公開対象)。

- `subscriptions.json`: Web Push購読情報を保存する場所。`[{"endpoint": "...", "keys": {"p256dh": "...", "auth": "..."}}]` という形式のリスト。個人利用・単一ユーザー想定のため、通常は1件のみ。存在しない場合、通知は単にスキップされる。

登録方法: アプリの「通知を有効にする」ボタンを押すと、購読情報がテキストエリアに表示される。その内容をこのファイルにコピー&ペーストしてコミットする(手動・一度だけでよい)。
